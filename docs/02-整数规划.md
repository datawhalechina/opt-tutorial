# 第 2 章 整数规划问题

整数规划（Integer Programming, IP）要求**决策变量取整数**。它比线性规划难，因为可选择的点变成了离散的，不能再用"沿边移动"的思路。

按变量类型分三类：

- **纯整数规划**：所有变量都是整数
- **混合整数规划**：一部分整数、一部分连续（第 3 章）
- **0-1 整数规划**：变量只能取 0 或 1，最常用

## 2.1 主要求解方法

| 方法 | 思路 | 说明 |
| :--- | :--- | :--- |
| 分支定界 | 先解掉整数约束的松弛问题，再对小数变量分支，用界剪枝 | 现代求解器的主干 |
| 割平面 | 加线性约束把松弛解"切"掉，逐步逼近整数解 | 与分支定界结合即 branch-and-cut |
| 动态规划 | 拆成重叠子问题 | 只适合特定结构，如背包 |
| 启发式 | 遗传、模拟退火、禁忌搜索等 | 不保证最优，用于超大规模 |

## 2.2 例题：0-1 背包

4 件物品，每件只能放或不放，背包容量 10：

| 物品 | 重量 | 价值 |
| :---: | :---: | :---: |
| 1 | 2 | 3 |
| 2 | 3 | 4 |
| 3 | 4 | 5 |
| 4 | 5 | 8 |

令 $x_i \in \{0,1\}$ 表示是否放入第 $i$ 件：

$$
\begin{aligned}
\max \quad & 3x_1 + 4x_2 + 5x_3 + 8x_4 \\
\text{s.t.} \quad & 2x_1 + 3x_2 + 4x_3 + 5x_4 \le 10 \\
& x_i \in \{0,1\}
\end{aligned}
$$

最优解：装 1、2、4 号，总重量 $2+3+5=10$，总价值 **15**。

> 注意别写成"件数"变量（$x_i$ 可以取 0、1、2…）。那样是**有界背包**，是另一个问题——原版教程这里就写错了。

## 2.3 Gurobi 写法

```python
import gurobipy as gp
from gurobipy import GRB

weights, values, capacity = [2, 3, 4, 5], [3, 4, 5, 8], 10

model = gp.Model("Knapsack")
x = model.addVars(len(weights), vtype=GRB.BINARY, name="x")   # 一次建 4 个 0-1 变量

model.setObjective(
    gp.quicksum(values[i] * x[i] for i in range(4)), GRB.MAXIMIZE
)
model.addConstr(
    gp.quicksum(weights[i] * x[i] for i in range(4)) <= capacity,
    name="Capacity",
)

model.optimize()
print(model.ObjVal)                    # 15
print([x[i].X for i in range(4)])      # [1.0, 1.0, 0.0, 1.0]
```

## 2.4 COPT 写法

```python
import coptpy as cp
from coptpy import COPT

weights, values, capacity = [2, 3, 4, 5], [3, 4, 5, 8], 10

env = cp.Envr()
model = env.createModel("Knapsack")

x = model.addVars(4, vtype=COPT.BINARY, nameprefix="x")        # 注意是 nameprefix

model.setObjective(
    cp.quicksum(values[i] * x[i] for i in range(4)), sense=COPT.MAXIMIZE
)
model.addConstr(
    cp.quicksum(weights[i] * x[i] for i in range(4)) <= capacity,
    name="Capacity",
)

model.solve()
print(model.objval)                                  # 15
print([x[i].x for i in range(4)])                    # [1.0, 1.0, 0.0, 1.0]
```

COPT 批量建变量生成的变量名是 `x(0), x(1), …`（括号下标），和 Gurobi 的 `x[0]` 不同，导出 LP 文件时能看到这个差别。

## 2.5 三种开源/商用写法的差异

| 操作 | Gurobi | COPT | CPLEX (docplex) | HiGHS | SCIP |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 0-1 变量 | `vtype=GRB.BINARY` | `vtype=COPT.BINARY` | `binary_var_list(n)` | `ub=1, type=kInteger` | `vtype="B"` |
| 整数变量 | `GRB.INTEGER` | `COPT.INTEGER` | `integer_var_list(n)` | `type=kInteger` | `vtype="I"` |
| 取解方式 | `x[i].X` | `x[i].x` | `sol.get_value(x[i])` | `model.variableValue(x[i])` | `model.getVal(x[i])` |

HiGHS 没有专门的 binary 类型，"0-1 变量"就是**下界 0、上界 1 的整数变量**：

```python
x = [
    model.addVariable(lb=0, ub=1, type=highspy.HighsVarType.kInteger, name=f"x{i+1}")
    for i in range(4)
]
model.setObjective(sum(values[i] * x[i] for i in range(4)), highspy.ObjSense.kMaximize)
```

用 `addVariable(obj=...)` 给目标系数也可以，但之后若再调用 `setObjective`，会把系数整体覆盖（不是叠加），两种写法选一种就好。

SCIP 用单字母 `vtype`：`"C"` 连续、`"I"` 整数、`"B"` 0-1。
