# 第 1 章 线性规划问题

线性规划（Linear Programming, LP）是最基础的优化问题：**目标函数和约束都是线性的，决策变量都是连续变量**。

这一章用同一道工厂生产题，把五个求解器的写法并排放一遍。看完这一章，五个求解器的基本套路就都认识了。

## 1.1 数学模型

标准形：

$$
\begin{aligned}
\max \quad & \mathbf{c}^\top \mathbf{x} \\
\text{s.t.} \quad & \mathbf{A}\mathbf{x} \le \mathbf{b} \\
& \mathbf{x} \ge 0
\end{aligned}
$$

- $\mathbf{x}$：决策变量
- $\mathbf{c}$：目标函数系数
- $\mathbf{A}, \mathbf{b}$：约束的系数矩阵和右端项

## 1.2 求解方法

**单纯形法**（Dantzig, 1947）：从一个顶点出发，沿可行域的边走到相邻顶点，直到不能再改进。直观、每步都在改善目标值；缺点是理论上可能循环（实际求解器用 Bland 规则等手段规避）。

**内点法**（Dikin 1967 提出，Karmarkar 1984 推广）：不走边界，从可行域内部沿牛顿方向逼近最优解。大规模问题上通常比单纯形快。

现代求解器两种都会实现，并自动选一个更合适的，你通常不需要关心——第 6 章讲日志时会看到它到底选了哪个。

## 1.3 例题：工厂生产计划

工厂生产 A、B 两种产品：

| 产品 | 单位利润（元） | 每件工时（h） | 每件原材料 |
| :--- | ---: | ---: | ---: |
| A | 40 | 2 | 3 |
| B | 50 | 4 | 1 |

可用工时 100 小时，可用原材料 50 单位。问各生产多少，利润最大？

令 $x_A, x_B$ 为两种产品的产量：

$$
\begin{aligned}
\max \quad & 40x_A + 50x_B \\
\text{s.t.} \quad & 2x_A + 4x_B \le 100 \quad\text{(工时)}\\
& 3x_A + x_B \le 50 \quad\text{(原材料)}\\
& x_A, x_B \ge 0
\end{aligned}
$$

最优解 $x_A=10,\ x_B=20$，最大利润 **1400**。

> 非负约束不要写成约束，建变量时直接给下界 `lb=0`，模型更小、求解更快。

## 1.4 五种写法

### Gurobi

```python
import gurobipy as gp
from gurobipy import GRB

model = gp.Model("Maximize_Profit")

a = model.addVar(lb=0, name="A")
b = model.addVar(lb=0, name="B")

model.setObjective(40 * a + 50 * b, GRB.MAXIMIZE)

model.addConstr(2 * a + 4 * b <= 100, name="Production_Time")
model.addConstr(3 * a + b <= 50, name="Raw_Material")

model.optimize()
print(model.ObjVal, a.X, b.X)
```

### COPT

```python
import coptpy as cp
from coptpy import COPT

env = cp.Envr()                         # COPT 必须先建环境
model = env.createModel("Maximize_Profit")

a = model.addVar(lb=0, name="A")
b = model.addVar(lb=0, name="B")

model.setObjective(40 * a + 50 * b, sense=COPT.MAXIMIZE)

model.addConstr(2 * a + 4 * b <= 100, name="Production_Time")   # ⚠️ 名字必须写 name=
model.addConstr(3 * a + b <= 50, name="Raw_Material")

model.solve()
print(model.objval, a.x, b.x)
```

### CPLEX（docplex）

```python
from docplex.mp.model import Model

model = Model("Maximize_Profit")

a = model.continuous_var(lb=0, name="A")
b = model.continuous_var(lb=0, name="B")

model.maximize(40 * a + 50 * b)

model.add_constraint(2 * a + 4 * b <= 100, ctname="Production_Time")
model.add_constraint(3 * a + b <= 50, ctname="Raw_Material")

sol = model.solve()
print(sol.objective_value, sol.get_value(a), sol.get_value(b))
```

### HiGHS（开源）

```python
import highspy

model = highspy.Highs()

a = model.addVariable(lb=0, name="A")
b = model.addVariable(lb=0, name="B")

model.maximize(40 * a + 50 * b)

model.addConstr(2 * a + 4 * b <= 100, "Production_Time")
model.addConstr(3 * a + b <= 50, "Raw_Material")

model.run()
print(model.getObjectiveValue(), model.variableValue(a), model.variableValue(b))
```

### SCIP（开源）

```python
from pyscipopt import Model

model = Model("Maximize_Profit")

a = model.addVar(vtype="C", lb=0, name="A")
b = model.addVar(vtype="C", lb=0, name="B")

model.setObjective(40 * a + 50 * b, sense="maximize")

model.addCons(2 * a + 4 * b <= 100, name="Production_Time")
model.addCons(3 * a + b <= 50, name="Raw_Material")

model.optimize()
print(model.getObjVal(), model.getVal(a), model.getVal(b))
```

五个脚本都能单独运行，输出都是：

```
最优目标值 = 1400
    A = 10
    B = 20
```

## 1.5 五个求解器 API 对照

| 操作 | Gurobi | COPT | CPLEX (docplex) | HiGHS | SCIP |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 建模型 | `gp.Model("m")` | `cp.Envr().createModel("m")` | `Model("m")` | `highspy.Highs()` | `Model("m")` |
| 建变量 | `addVar(lb=0, name="x")` | `addVar(lb=0, name="x")` | `continuous_var(lb=0, name="x")` | `addVariable(lb=0, name="x")` | `addVar(vtype="C", lb=0, name="x")` |
| 批量建变量 | `addVars(n, vtype=…, name="x")` | `addVars(n, vtype=…, nameprefix="x")` | `continuous_var_list(n, name="x")` | 列表推导 + `addVariable` | 列表推导 + `addVar` |
| 目标函数 | `setObjective(expr, GRB.MAXIMIZE)` | `setObjective(expr, sense=COPT.MAXIMIZE)` | `maximize(expr)` | `maximize(expr)` | `setObjective(expr, sense="maximize")` |
| 单条约束 | `addConstr(expr, name="c")` | `addConstr(expr, name="c")` ⚠️ | `add_constraint(expr, ctname="c")` | `addConstr(expr, "c")` | `addCons(expr, name="c")` |
| 批量约束 | `addConstrs(gen, name="c")` | `addConstrs(gen, nameprefix="c")` | `add_constraints(gen, names=[…])` | 循环 | 循环 |
| 求和 | `gp.quicksum(…)` | `cp.quicksum(…)` | `model.sum(…)` | 内置 `sum(…)` | `quicksum(…)` |
| 求解 | `optimize()` | `solve()` | `solve()` | `run()` | `optimize()` |
| 目标值 | `model.ObjVal` | `model.objval` | `sol.objective_value` | `model.getObjectiveValue()` | `model.getObjVal()` |
| 变量值 | `var.X` | `var.x` | `sol.get_value(var)` | `model.variableValue(var)` | `model.getVal(var)` |
| 变量名 | `var.VarName` | `var.getName()` | `var.name` | `var.name` | `var.name` |
| 模型状态 | `model.Status == GRB.OPTIMAL` | `model.status == COPT.OPTIMAL` | `sol is not None` | `getModelStatus() == kOptimal` | `getStatus() == "optimal"` |
| 关闭日志 | `Params.OutputFlag = 0` | `setParam("Logging", 0)` | `solve(log_output=False)` | `setOptionValue("output_flag", False)` | `hideOutput()` |

注意三处容易踩的坑：

1. **COPT 的 `addConstr` 第二个位置参数是 `sense` 不是 `name`**，写 `addConstr(expr, "名字")` 名字会被静默丢掉，必须写 `name=`。
2. **HiGHS 用内置 `sum()` 拼表达式**，没有 `quicksum`。
3. **COPT 关日志是 `Logging`**，`LogToConsole` 不是开关。
